<div>
  <h3>Overview</h3>
  <p>
    Filmy is a movie and series platform with free and premium subscription plans, user authentication, and content access control.
  </p>
</div>

<div>
  <h3>Features</h3>
  <ul>
    <li>User registration and login</li>
    <li>JWT authentication</li>
    <li>Free and premium subscription plans</li>
    <li>Movie and series catalog</li>
    <li>Content access control based on subscription</li>
    <li>Swagger API documentation</li>
  </ul>
</div>
